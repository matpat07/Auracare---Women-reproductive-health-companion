# Deslop

A running checklist of the tells that make design and writing look
AI-generated by default. Run output against this before calling it done —
don't wait to be asked.

## Visual design slop

- **Drop shadows on everything** — cards, buttons, and icons all getting a
  soft shadow "for depth." Use a border, a flat fill, or real spacing instead.
- **Gradient hero backgrounds** — purple-to-pink or blue-to-teal gradients as
  the default "premium" look. Pick one intentional color and commit to it.
- **Glassmorphism / backdrop-blur** — frosted-glass panels dropped in without
  a reason tied to the content.
- **Highlight bars / accent strips** — a colored bar down the side or top of
  a card that decorates rather than communicates. If it doesn't encode a real
  status or category, cut it.
- **Icon-in-a-circle + heading + paragraph, times three** — the default
  "features" grid. Fine occasionally, but not the answer to every section.
- **Decorative pill badges** — "New," "Pro," "Fast" tags added for visual
  texture rather than because they're true and useful right now.
- **Emoji as bullet points or section icons.**
- **Centered hero: big bold headline, subhead, two buttons** — the default
  layout reached for regardless of what the page is actually for.
- **Isometric-people / blob-shape stock illustrations.**
- **Padding as a substitute for hierarchy** — lots of whitespace used to look
  "clean" instead of actual visual priority between elements.
- **Rounded corners on every element at the same radius**, with no relation
  to what's a container vs. an interactive element.

## Writing / copy slop

- **Em dashes standing in for real sentence structure** — used to avoid
  deciding whether something is a new sentence, a comma, or a colon.
- **"In today's fast-paced world..." / "In the ever-evolving landscape
  of..."** — throat-clearing opening lines that delay the actual point.
- **"It's not just X, it's Y."** — the reflexive contrast construction.
- **"Let's dive in" / "Without further ado."**
- **Tricolon padding** — "clean, modern, and intuitive," "fast, flexible,
  and reliable" — three adjectives standing in for one specific claim.
- **Buzzword inflation** — leverage, seamless, elevate, unlock, revolutionize,
  game-changer, cutting-edge, robust, "next-level."
- **Forced rhetorical questions** — "Ever wondered how...?"
- **Random bolding** for emphasis instead of actual structure.
- **Restating a bullet list in prose right after showing it as bullets.**
- **A closing paragraph that just re-summarizes everything above it.**
- **Exclamation-point enthusiasm on every line**, regardless of content.

## Interaction / motion slop

- **Hover-scale on every card**, whether or not the card is a button.
- **Fade-in-on-scroll applied to every single element** rather than the one
  or two that benefit from it.
- **Micro-interactions with no functional meaning** (confetti, bounce,
  pulse) added because they're easy, not because they earn their place.

## Self-check before finishing

Scan the output for: drop shadows, gradients-as-default, pill badges,
highlight bars, em dashes, buzzwords, a three-card icon grid. For each one
found, ask "does this serve the content, or is it filler?" — cut the filler
rather than justify it after the fact.
