# Preferred web components

The user wants refined, neat website components from the sources below, or similar custom implementations. devl.dev is their strongest preference. Treat these as defaults for relevant website work; the current brief and an existing project's design system take precedence.

## Sources and selection

- https://www.devl.dev/ — primary reference. Inspect the relevant experiment for the actual screen or component. It links to https://coss.com/ui as its component foundation; verify current documentation and exact link before choosing dependencies. Some experiments are marked WIP.
- https://www.beautifului.dev/ — AI interface patterns such as prompt bars, task rows, context cards, tables, and agent states.
- https://www.aicss.dev/ — AI conversation components, streaming output, code blocks, tool states, and structured responses.
- https://www.fluidfunctionalism.com/ — controls and functional interaction details, including spring and hover behavior.
- https://dotmatrix.zzzzshawn.cloud/ — dot matrix loaders when appropriate to the product.
- https://magicui.design/docs/components/ — selectively use motion and visual components appropriate to the brief.
- https://glass.samasante.com/?view=docs — glass/refraction reference when appropriate. Inspect live documentation before making implementation or browser-support claims.
- https://uselayouts.com/browse - Cool components

## Implementation approach

Choose relevant examples, inspect their rendered appearance and interactions, then use available source components when compatible with the project and their license. Check actual installation documentation and dependencies instead of guessing package names. If source is unavailable or unsuitable, implement a similar component in the project's existing stack and describe it as inspired by the reference.

Use the selected reference to inform spacing, typography, proportions, borders, surfaces, hierarchy, and interaction behavior. Unify adapted components with the project's tokens. Avoid importing every library or combining unrelated visual effects simply because they appear in this list. Preserve keyboard interaction, responsive behavior, and reduced-motion support.

Do not install project dependencies until there is a concrete project requiring them. This skill saves preferences and reference routing; it does not bundle the websites' code or grant permission to purchase paid components.
